# 🎓 Acadexa

AI Academic Copilot is an AI-powered learning platform designed for Diploma and Engineering students.  
It provides smart academic assistance through AI chatbot, study tools, notes, quizzes, previous papers, and personalized learning features.

## 🔗 Live Demo
(https://yogitadalvi.pythonanywhere.com/)

## 📋 Features: 
## 👨‍🎓 Student Features
- User Registration and Login
- Student Dashboard with learning activity tracking
- AI Academic Chatbot for subject-related queries
- AI Study Roadmap Generator
- AI Study Planner
- AI Notes Summarizer
- AI Viva Question Generator
- Subject-wise Notes Access
- Previous Year Question Papers
- Online Subject-wise Quiz
- Quiz Result Tracking
- Leaderboard System
- Profile and Progress Tracking

## 👨‍💼 Admin Features
- Secure Admin Login
- Admin Dashboard
- Manage Users
- View User Activity
- Change User Roles (Student/Admin)
- Upload Previous Year Papers
- Edit and Delete Papers
- View Chat History
- Monitor Learning Activities
